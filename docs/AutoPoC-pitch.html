문제 정의

  • 감사의 병목은 "확인"이다. 정적 분석·LLM 도구는 취약 가능성을 쏟아내지만, 진짜 성립 여부 판단은 사람 몫 — 느리고 비싸다.
  • "가능성 리포트"는 신뢰할 수 없다. 오탐(false positive)이 섞여 있어, 리포트 한 줄마다 사람이 다시 검증해야 한다.
  • 재현이 어렵다. 같은 입력에도 결과가 흔들리면 회귀 검증·감사 추적이 불가능하다.
  • → 필요한 것: 공격 성립을 스스로 · 재현 가능하게 · 오탐 없이 증명하는 자율 에이전트.

위협 모델

입력 & 공격자 능력

타깃 컨트랙트 소스 + 불변식(Invariants) + manifest를 입력받는다. 공격자는 임의 트랜잭션 시퀀스·재진입·외부 콜·자금 이동을 수행할 수 있다.

성공의 정의

조직위 하네스 IInvariants.checkAll이 실제로 깨져야만 성공. 에이전트도 LLM도 판정 권한이 없다 — 판정은 forge 실행뿐.

신뢰 경계

LLM은 소스 추론만 한다 — 파일·웹 접근 없음, 타깃별 정답 하드코딩 없음. 모든 후보는 하네스 실행으로만 채택된다.

안전장치

멀쩡한 타깃엔 거짓 성공을 만들지 않고 기권(exit 1). 네트워크는 허용된 LLM API 예외만 — 오프라인에선 완전 차단으로도 동작.

두뇌 앙상블 & 라우팅

하나의 검증 게이트

강점 01

증명되지 않으면 성공이 아니다

실행 · 오탐

실행 증명 게이트

모든 후보는 forge 하네스로 실제 실행되어 checkAll을 실제로 깰 때만 채택된다. "될 것 같다"는 후보는 산출물이 되지 못한다. 판정 권한은 하네스뿐.

오탐 0 — 멀쩡하면 기권

취약하지 않은 타깃은 예산을 다 써도 exit 1로 기권한다. 거짓 성공(false positive)을 구조적으로 만들지 않는다.

제출되는 모든 성공은 이미 실행으로 증명된 것 — 실행·재현 실패 리스크를 산출 단계에서 제거하고, 취약/정상 컨트랙트를 exit 0 / exit 1로 명확히 가른다.

강점 02

언제 돌려도 똑같다

결정론

솔루션 캐시

성공한 PoC를 (타깃 소스 해시, 시드)로 고정. 재실행은 LLM을 다시 부르지 않고 바이트 동일하게 리플레이한다.

LLM 비의존 결정론

퍼저 시드 고정 + 오프라인 결정론 두뇌 우선. 결정론이 LLM 온도·샘플링에 흔들리지 않는다.

검증됨

오프라인 N=3 바이트 동일 신규 생성 + 클라우드 캐시 리플레이 동일로 실측 확인.

동일 조건 → 동일한 PoC. 생성 경로(캐시 없는 재생성)와 재현 경로(캐시 리플레이)가 모두 결정론적이라, 회귀 검증과 감사 추적이 가능하다.
강점 ② 결정론 & 캐시 일관성07 / 10
강점 03

베끼지 않고, 스스로 뚫는다

자체 도출 · 일반화

스스로 도출

정답 하드코딩 없음. 클라우드 브레인은 파일·웹 접근이 없어 넘겨준 소스만 본다. 퍼저는 사전지식 0으로 반례를 탐색 — 공개 익스플로잇 "재현"이 아니다.

미공개 일반화

모델 폴백 체인(sonnet-5 → opus-4-8)이 처음 보는 유형을 추론으로 공략. 실측 포팅 미공개 8/8 발견.

최소 PoC

퍼저의 축약된 반례에서, 호출하는 인터페이스만 선언한 self-contained run(address) PoC를 합성.

에이전트가 소스로부터 직접 도출한 경로이고(암기·카피 불가), 처음 보는 타깃으로 일반화되며, 산출물은 재현 가능한 최소 PoC다.

왜 AutoPoC인가

증명 기반

"의심"이 아니라 실행되는 PoC. 하네스가 깨져야만 성공 — 사람이 다시 검증할 필요가 없다.

캐시 결정론

같은 입력 → 바이트 동일 결과. LLM 비결정성과 무관하게 재현·감사 가능.

오탐 0

멀쩡한 타깃엔 기권. 리포트의 모든 성공이 실제 성립임을 보장.

스스로 도출

파일·정답 접근 없이 소스에서 직접 유도 — 공개 익스플로잇 카피가 아니다.

미공개 일반화

폴백 체인으로 처음 보는 유형까지 공략, 포팅 8/8.

최소 PoC

축약 반례 기반 self-contained run(address).

실행되는 PoC = 신뢰. AutoPoC는 취약점을 주장하지 않고 증명한다.
